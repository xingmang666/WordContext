# 词境 (WordContext) - 基于大语言模型的智能语境生成英语学习系统

## 📖 项目简介
本项目是一个面向高中生的智能英语学习桌面软件。针对传统单词软件“重记忆轻应用”的痛点，采用 Java Swing 开发前端界面，接入 DeepSeek 大模型 API。系统根据用户默写的错题，动态生成定制化的“完形填空”与“语法填空”，实现个性化语境生成与练习闭环。

## ✨ 核心功能
- **本地词库**：解析 JSONL 格式词库（含英/美双音标）。
- **背词与默写**：中英互译输入校验，即时错误提示与生词收集。
- **AI 动态出题**：完成默写后，可选择生成“完形填空”（单选）或“语法填空”（填空）。
- **智能解析**：提交试卷后自动判分，展示 AI 生成的语法与逻辑解析。
- **鲁棒性兜底**：无网络或未配置 API Key 时，自动切换离线演示模式，保证 UI 交互不崩溃。

## 🛠️ 技术栈
- **语言**：Java (JDK 21)
- **UI 框架**：Java Swing + FlatLaf (现代化扁平主题)
- **网络请求**：OkHttp 3
- **JSON 解析**：Jackson
- **AI 引擎**：DeepSeek API (deepseek-chat)
- **打包部署**：Maven Shade + jpackage

## 🚀 如何运行
1. 克隆本项目到本地。
2. 运行 `org.example.Main` 类的 main 方法。
3. 点击软件内的“设置 API Key”输入密钥（或留空直接体验离线演示模式）。
